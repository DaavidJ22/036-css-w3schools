Propiedad overflow en CSS

Overflow visible

Este contenido es demasiado largo para caber dentro del elemento. Con overflow visible, el contenido continúa mostrándose fuera de los límites de la caja.

Overflow hidden

Este contenido es demasiado largo para caber dentro del elemento. Con overflow hidden, la parte que sale de la caja queda oculta.

Overflow scroll

Este contenido es demasiado largo para caber dentro del elemento. Con overflow scroll, aparecen barras de desplazamiento para poder observar el contenido completo.

Overflow auto

Este contenido es demasiado largo para caber dentro del elemento. Con overflow auto, las barras aparecen solamente cuando son necesarias.
